# Executar no Replit

- O workflow `Start application` inicia a aplicação com `HOST=0.0.0.0 PORT=5000 node server.mjs`. O preview do Replit usa a porta 5000.
- Requer Node.js 22.5 ou superior; este projeto usa Node.js 24 no Replit e não precisa instalar dependências.
- Na primeira visita, crie o usuário administrador. A senha precisa ter pelo menos 12 caracteres.
- Os dados locais são gravados em `data/`. A integração de IA é opcional e precisa de uma chave OpenAI configurada no app.
